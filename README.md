# Демо мини-приложений

Три кликабельных прототипа в стиле Telegram Mini Apps. Чистые HTML, CSS и JS без сборки, данные хранятся в `localStorage`.

| Приложение | Папка | Что внутри |
|---|---|---|
| Out of Box | `out-of-box/` | Диалоги Dating English, мемы с квизом, кристаллы, профиль, серия дней |
| VTG Каталог | `vtg/` | Каталог, фильтры, поиск, избранное, корзина, промокод `VTG10`, оформление заказа |
| Piastrix Wallet | `piastrix/` | Витрины, покупка кодов, пополнение, переводы, история, старый/новый дизайн |

Локальный запуск:

```bash
python3 -m http.server 5190
```

Затем открыть `http://localhost:5190/`.

Платежи, выдача кодов и доставка в демо учебные. Места подключения внешних сервисов отмечены в интерфейсе пометкой «Подключение».
