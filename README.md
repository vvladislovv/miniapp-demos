# Три демо-приложения

Три кликабельных адаптивных прототипа (телефон и ПК). Чистые HTML, CSS и JS без сборки, данные хранятся в `localStorage`.

| Приложение | Папка | Что внутри |
|---|---|---|
| Speakeasy | `speakeasy/` | Диалоги для свиданий, мемы с квизом, искры, профиль, серия дней |
| Архив №9 | `archive09/` | Каталог, фильтры, поиск, избранное, корзина, промокод, оформление заказа |
| Lume | `lume/` | Витрины, покупка кодов, пополнение, переводы, история |

Локальный запуск:

```bash
python3 -m http.server 5190
```

Затем открыть `http://localhost:5190/`.

Платежи, выдача кодов и доставка в демо учебные. Места подключения внешних сервисов отмечены в интерфейсе пометкой «Подключение».
